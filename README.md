# AstroPath — React + Vite (migration of v48)

**Исходная версия:** `AstroPath_Lagrange_Full_Methodology_v48(1).html` (11 ноября 2026).

Это **реальная миграция интерфейса** AstroPath на React. Основные страницы, навигация, каталог теории, страница урока, фильтры практики, подсказки, решения и локальный прогресс работают через компоненты React. Содержимое уроков и задач извлечено без редактирования из исходного HTML.

## Состав

- 25 разделов, **120 уроков**, **421 уникальная задача**.
- 111 подробных учебных блоков/уроков с контентом; остальные темы остаются в программе.
- 15 конфигураций симуляторов из исходного проекта, без переписывания математических функций.
- Полная встроенная версия MathJax (без зависимости от CDN).
- Сохранён CSS из исходного сайта и копия исходного HTML для сверки.
- Сохранены 6 практикумов IOAA и 9 карточек подробных уроков.
- Локальные отметки из старого сайта: `astropath_solved`, `astropath_lessons_v2`.

## Как запустить на Windows

1. Установить **Node.js LTS** с https://nodejs.org.
2. Распаковать ZIP в папку, например `C:\AstroPath`.
3. Открыть папку в терминале PowerShell (или VS Code → Terminal).
4. Выполнить:

```powershell
npm install
npm run dev
```

5. Открыть URL, напечатанный Vite, обычно `http://localhost:5173/`.

### Для публикации

```powershell
npm run build
```

В папке `dist/` окажется готовый статический фронтенд. Контрольный файл `backup/original-v48.html` не попадает в `dist/`. Его можно выложить на Cloudflare Pages, Netlify или другой сервис с поддержкой статических сайтов. До появления backend-проверки нельзя класть закрытые платные уроки в публичный `dist/`.

## Важно: это только этап 1

**Пока нет** сервера, Supabase Auth, пользовательских аккаунтов, Stripe, выдачи платных доступов, серверной проверки решений, защищённого начисления XP. Текущие отметки работают в браузере через localStorage, как в исходном проекте. Не воспринимайте кнопку «Решено» как проверку правильности задачи.

Для коммерческого запуска отдельно реализовать Cloudflare Workers + PostgreSQL/Supabase + Stripe Webhooks и перенести защищённые решения и платные уроки за API.

  data/hints.js            Подсказки оригинальной версии
  data/news.js             Оригинальные новости

## Что остаётся переходным

- Часть подробных методичек хранится как HTML-строки, которые React показывает без изменения оригинального содержимого.
- SVG-симуляторы используют точный исходный код `refreshSimulator()`, подключённый к React lifecycle.
- Главные карточки и практикумы импортированы как доверенный HTML из оригинального сайта.

Это сознательный выбор, чтобы не потерять авторские объяснения и математические расчёты. Впоследствии редактор уроков можно перевести на структурированные блоки без изменения содержания.

## Проверка

Данные модулей автоматически проверены на синтаксис Node.js. Непосредственная сборка `npm run build` в среде генерации **не проводилась**: npm registry не доступен из этой среды. После `npm install` рекомендуется выполнить тест на мобильном устройстве и сравнить симуляторы с оригиналом.
